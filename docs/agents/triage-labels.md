# Triage labels

Map the engineering skills' canonical roles to these exact GitHub label names.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue. |
| needs-info | needs-info | Waiting for information needed to proceed. |
| ready-for-agent | ready-for-agent | Specified work suitable for agent implementation. |
| ready-for-human | ready-for-human | Work requiring human implementation. |
| wontfix | wontfix | Work that will not be actioned. |

Use the mapped label whenever a skill names a triage role. A label does not itself override the project's implementation-authorization boundary.
